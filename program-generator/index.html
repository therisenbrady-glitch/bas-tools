In WorkStation, right-click the MP controller and choose Export. The file tells the generator the model, its free terminals and the room sensor.

Boiler plants run on an AS-P with SmartX IO modules, so there's no export to open. Name the server and list the modules on its IO Bus; points get a module channel in step 4.
