Tips

  • iPhone: open this page in Safari and tap Share → Add to Home Screen. Do the same inside each tool you use so it opens like an app, and so Safari doesn't clear your saved jobs.
  • Android: open this page in Chrome and tap ⋮ → Add to home screen (or Install app). Do the same for each tool.
  • Camera, downloads, and file-picker help for both is in Manuals → Phone setup.
  • Jobs save in the browser on your device. Use Export job to back one up or hand it to someone else.
  • Typical flow: scan at install, then at checkout import the EBO XML and the scanner's Export for checkout file into the tracker. The Job workflow manual walks through it step by step.
