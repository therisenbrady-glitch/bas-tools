Point List Generator

Load a picture of a controller wiring diagram. Claude reads what lands on each terminal, you check the table, and the page draws a clean I/O diagram and point list.

Tip: shoot the page straight on, fill the frame with the controller and its wire labels, and avoid glare. A screenshot from the PDF works best.

Reading the diagram. This takes about a minute.

No API key? Open the Claude version of this tool. It reads the picture with your own Claude account instead, and works the same way.

Reading uses your own Claude account and counts toward your plan's usage, like sending Claude a message with a picture. The first time, Claude asks you to allow it.

Claude API key

Reading a diagram sends the picture to Anthropic's Claude API using your own API key, which you get at console.anthropic.com under API keys. The key is saved only in this browser on this device. Each diagram costs about 10 to 20 cents. Without a key you can still type the points in below.

Or start from an EBO or Niagara exportRight-click the controller (or a whole server) in WorkStation, Export, and open the .xml here. It lists every hardware point on its terminal, plus the spares. A Niagara .bog with MP or RP controllers under the Schneider MPX driver works too. For an I/NET site you can also open the server's backup (.xbk) or I/NET controller saves (DCUnnnn.SAV, several at once).

Or start from a TAC I/NET boardPick the board and its expansion card. Every terminal is filled with its I/NET point address and screw terminals from the TCON pinouts; then type the I/NET names, or read a wiring picture.
Or draft a new controllerFor a drawing before install (for the electrician): pick the model and every terminal is listed as a spare. Type the point names and set each Ub to AI, DI, AO or DO, then tap a point in the diagram to plan its wiring.

02Controller and points

Addresses

LL SS CC PP. Type CC PP in the table; link and station come from here.

TerminalWire #TypeDevicePoint nameDescriptionSignal / notes

Name terminals the way the controller labels them (Ub 1, DO 1, UI 3, COM A). Leave the point name empty for a spare. Typing a point name like SaTmp fills the type and description if they're empty.

03I/O diagram

The diagram appears here once the table has points.

Tap a named point in the diagram to plan its wiring.

03Wiring

Drag the round end of each conductor onto a screw or onto the X1 / X2 block. Drag the X1 and X2 blocks wherever suits the drawing. Tick Hot through low limit for anything a low temp trip must kill (fans, CHW valve, cooling): its hot moves to X1S, which is fed from X1 through the low limit, so the controller itself stays powered. Type the device's own terminal names above.

04Save

The job file keeps the picture and the table so you can pick it up on another device. Point names and terminal names follow the Program Generator's conventions.

Everything stays on this device except the picture you send to Claude when you tap Read.
