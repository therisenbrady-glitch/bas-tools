Load a picture of a controller wiring diagram. Claude reads what lands on each terminal, you check the table, and the page draws a clean I/O diagram and point list.

Tip: shoot the page straight on, fill the frame with the controller and its wire labels, and avoid glare. A screenshot from the PDF works best.

Reading the diagram. This takes about a minute.

No API key? Open the Claude version of this tool. It reads the picture with your own Claude account instead, and works the same way.

Reading uses your own Claude account and counts toward your plan's usage, like sending Claude a message with a picture. The first time, Claude asks you to allow it.

Claude API key

Reading a diagram sends the picture to Anthropic's Claude API using your own API key, which you get at console.anthropic.com under API keys. The key is saved only in this browser on this device. Each diagram costs about 10 to 20 cents. Without a key you can still type the points in below.

Name terminals the way the controller labels them (Ub 1, DO 1, UI 3, COM A). Leave the point name empty for a spare. Typing a point name like SaTmp fills the type and description if they're empty.
