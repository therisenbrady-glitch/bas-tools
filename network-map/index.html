Network Map

Run the scan on a laptop plugged into the controller network, then load its CSVs here to see every controller, its address, and the cable order.

01Get the scan kit

  1. Download the kit on a Windows laptop and unzip it.
  2. Plug into the controller network, close EBO WorkStation, and double-click Run EBO-NetScan.bat. The map opens in the browser when it's done, no internet needed.
  3. For the cable order, install Wireshark (with Npcap) and take a reading at a few spots along the chain. The kit's README explains where.
